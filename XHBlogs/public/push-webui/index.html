推送小贴士

  • versionCode 必须递增：客户端通过它判断是否需要更新。
  • 已存在的 (appId, platform, code) 不可重复推送，先在「版本管理」删除旧的。

🌐 FCM HTTP 代理

解决国内直连 oauth2.googleapis.com 被 GFW 阻断

Google 的 OAuth2 / FCM API 域名（oauth2.googleapis.com / fcm.googleapis.com）在国内被 GFW 阻断。 你电脑如果已经跑了 HTTP/HTTPS 代理（如 Clash、V2Ray、Shadowsocks），填到这里 SEA 就能走代理连 Google。

格式：http://[user:pass@]host:port · 留空 = 直连

☁️ Cloudflare Worker 中转 推荐

SEA → Cloudflare 边缘（国内可达） → Google FCM

推荐方案：在 Cloudflare Dashboard 部署一个 Worker，把 Firebase service account 塞到 Worker 环境变量。 SEA 调 Worker 的 /send 端点，Worker 内部换 access_token + 调 Google FCM。 优势：SEA 只连 Cloudflare 边缘（国内可达），完全绕开 GFW，不需要在本机跑任何代理。

格式：https://<name>.<subdomain>.workers.dev
SEA 调 Worker 时用 Bearer token 传，留空 = 不变

发送推送

不选则走"广播"，或下方手填 token
💡 token 是什么？ FCM token 是 Google 给每台设备的"地址"（base64 字符串，约 152-200 字符）。app 启动时 Google Play Services 找 FCM 要一个，app 再报给 pushServer（POST /api/fcm/register）。pushServer 有了 token 就能往对应设备发推送。
